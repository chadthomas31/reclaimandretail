# Reclaim & Retail

A responsive storefront for Reclaim & Retail, an online reseller of wholesale and liquidation merchandise.

## Technology

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Vercel-ready deployment

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

Import this repository into Vercel. Vercel will detect Next.js automatically, so the default build settings are sufficient.
